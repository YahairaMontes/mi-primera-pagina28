 <h1>Unidad 1: Fundamentos de Programación</h1>
  <p>
     En clase aprendimos que la programación es el proceso de crear instrucciones que una computadora puede entender y ejecutar.
     Todo esto se basa en dos grandes componentes: <b>hardware</b> y <b>software</b>.
  </p>

 <h2>Hardware y Software</h2>
    <p>
     El <b>hardware</b> es la parte física del computador, como el teclado, el monitor o el procesador.
     El <b>software</b>, en cambio, es la parte lógica: los programas que le indican al hardware qué hacer.
     También aprendimos un dato interesante: antiguamente se utilizaban los <b>ábacos</b> para representar números
     de manera física, lo que se puede considerar una forma primitiva de hardware.
    </p>

 <h2>Cómo surge el software a partir del hardware</h2>
      <p>
         El software surge porque las personas necesitaban una forma de darle órdenes al hardware para realizar tareas más complejas.
         Con el tiempo, se crearon sistemas que traducen las instrucciones humanas en un lenguaje que las máquinas pueden entender.
         Así nacieron los <b>lenguajes de programación</b>, que permiten comunicarnos con las computadoras mediante código.
     </p>

 <h2>Bits y la información</h2>
        <p>
         Los <b>bits</b> son la unidad mínima de información en la  informática.
         Un bit puede tener solo dos valores: 0 o 1, que representan los estados eléctricos del hardware (apagado o encendido).
         Al combinar varios bits se pueden formar letras, números, imágenes y cualquier tipo de información.
        </p>
            <ul>
              <li>1 bit puede representar dos valores: 0 o 1.</li>
              <li>8 bits forman un <b>byte</b>, que puede representar un carácter, como una letra o un número.</li>
            </ul>

 <h2>Algoritmos</h2>
        <p>
         Un <b>algoritmo</b> es un conjunto de pasos ordenados y lógicos que permiten resolver un problema.
         En programación, esos pasos se traducen en instrucciones que la computadora ejecuta una por una.
         El pensamiento algorítmico consiste en analizar un problema y dividirlo en partes pequeñas que la computadora pueda entender.
        </p>

 <h2>Lenguajes de programación</h2>
        <p>
         Un <b>lenguaje de programación</b> es una herramienta que permite escribir algoritmos e instrucciones que la computadora puede interpretar y ejecutar.
         Existen distintos tipos de lenguajes:
        </p>
    <ul>
        <li><b>Interpretados:</b> ejecutan el código línea por línea. Ejemplo: Python, Bash.</li>
        <li><b>Compilados:</b> traducen todo el código antes de ejecutarlo. Ejemplo: C, C++.</li>
        <li><b>Intermedios:</b> combinan ambas formas. Ejemplo: Java.</li>
    </ul>

 <h2>¿Qué es un programa?</h2>
        <p>
         Un <b>programa</b> es un conjunto de instrucciones escritas en un lenguaje de programación para resolver un problema o realizar una tarea específica.
         Por ejemplo, puede ser un programa para sumar números, mostrar mensajes o realizar cálculos.
        </p>

 <h2>Variables</h2>
        <p>
         Una <b>variable</b> es un espacio en la memoria donde se guarda información que puede cambiar durante la ejecución del programa.
         Cada variable tiene un nombre y un valor.
        </p>
    <p>Ejemplo básico:</p>
    <pre>
nombre = "Sara"
edad = 20
    </pre>

 <h2>Controladores de flujo</h2>
        <p>
         Los <b>controladores de flujo</b> permiten que un programa tome decisiones o repita acciones según ciertas condiciones.
         Gracias a ellos, los programas pueden comportarse de manera más dinámica.
         Por ejemplo, se utilizan para verificar si una persona cumple cierta condición o para decidir qué acción realizar a continuación.
        </p>

 <h2>Ejemplo sencillo en Python</h2>
    <p>A continuación, un ejemplo muy simple de programa en Python:</p>
    <pre>

 # Programa básico en Python

 nombre = "Sara"
 mensaje = f"Hola, {nombre}. ¡Bienvenidos a programación!"
 print(mensaje)
    </pre>
    <p>
        Este programa guarda un nombre en una variable y muestra un saludo en pantalla.
        Es un ejemplo básico, pero demuestra cómo el software (el código) le da instrucciones al hardware para ejecutar una tarea.
    </p>
